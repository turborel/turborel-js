# Appendix A: Types

[Contents](README.md)

Every data type and value tag of the protocol, version 1, and the JavaScript value it is read as and sent from: `bigint` and `Decimal` for exact numbers, `number` for approximate ones, and the driver's choices for datetimes, intervals, large objects, JSON, XML and UUIDs. Milestone M1 decides the mapping and fills this table.
