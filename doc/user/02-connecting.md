# Connecting

[Contents](README.md)

How a program connects to a server: over TCP, a Unix socket or a Windows named pipe; with TLS and the server's certificate verified; proving its user by password, SCRAM-SHA-256, a certificate or trust; with timeouts; and how a connection is closed. Milestone M2 builds the connection and fills this chapter, and milestone M7 gives its examples in the standard API.
