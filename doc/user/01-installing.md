# Installing

[Contents](README.md)

What turborel-js needs, Node.js 22.12 or later on Linux, macOS or Windows and a turborel server of the same release, and how it is installed: from npm once it is published, and from source until then. It is completed in milestone M7, when the standard API it shows is built; until then the [README](../../README.md) says how to build the driver from source.
